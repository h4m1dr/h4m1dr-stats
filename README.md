# h4m1dr-stats — Deprecated

> **Deprecated.** All stats generation moved to
> **[h4m1dr/h4m1dr-profile-stats](https://github.com/h4m1dr/h4m1dr-profile-stats)**,
> the single engine behind the GitHub profile widgets. This repo is kept for
> history only and receives no updates.

## What moved where

| Used to live here | Now lives in `h4m1dr-profile-stats` |
| --- | --- |
| Top Languages SVG | `assets/top_langs.svg` (live, real data) |
| Weekly / monthly activity | `assets/weekly_activity.svg`, `assets/monthly_activity.svg` (placeholders for now) |
| WakaTime stats | `assets/wakatime.svg` (placeholder for now) |

The weekly/monthly text blocks that used to be generated into this README are
now generated by the profile repo itself
(`h4m1dr/scripts/update_ascii_activity.py`), and the WakaTime section by its
`waka-readme.yml`.

## What this repo was

It generated a Top Languages SVG plus weekly/monthly GitHub activity text
blocks from the GitHub GraphQL API, updated daily by GitHub Actions. The code
is identical to the copy in `h4m1dr-profile-stats`.
